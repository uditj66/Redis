🎯

What is it?

A probabilistic data structure that tells you whether an item is definitely NOT in a set, or possibly in it.

⚡

Why use it?

Extremely fast O(k) lookups and tiny memory footprint — no false negatives, but rare false positives.

🔑

Key Insight

Multiple hash functions map each item to positions in a bit array. All bits must be 1 for a "possible yes".

🏗️

Real Uses

Redis, Chrome safe-browsing, Cassandra, spell checkers, CDN caches, blockchain, and more.

📖 How It Works

Three simple rules power everything.

🗄️

Bit Array

Start with an array of m bits, all set to 0.

#️⃣

k Hash Functions

When adding an item, run it through k different hash functions, each giving a position.

💡

Set Bits

Set bit[h1(x)], bit[h2(x)], bit[h3(x)] to 1.

🔍

Query

Check all k positions. If any bit is 0 → definitely absent. All 1s → possibly present.

3 Knowledge Check

Test your understanding with these quick questions.

Q1: A Bloom Filter says an item is "possibly in the set." What can you conclude?
🔴 The item is definitely in the set
🟡 The item might be in the set — there could be a false positive
🔵 The item is definitely NOT in the set
Q2: When a Bloom Filter says "definitely NOT in set", can it be wrong?
✅ No — Bloom Filters have zero false negatives
❌ Yes — it could still be wrong (false negative)
🤷 It depends on the hash functions
Q3: What happens to the false positive rate as you add MORE items?
📈 It increases — more bits get set, collisions become likely
📉 It decreases — more data means more accuracy
📊 It stays constant regardless of load
Q4: You add "apple" to the filter. Can you later remove "apple" from it?
🚫 No — standard Bloom Filters don't support deletion
✅ Yes — just flip its bits back to 0
🔄 Yes — but only if you reset the whole filter first
4 Real-World Applications

Where Bloom Filters shine in production systems.

🌐

Chrome Safe Browsing

A Bloom Filter of malicious URLs is stored locally. Before checking a remote database, Chrome checks the filter — saving millions of network calls.

🗄️

Redis / Cassandra

Before reading from disk (slow), check a Bloom Filter if the key exists. If it says "no" — skip the disk read entirely!

📧

Spam Detection

A Bloom Filter of known spam email addresses lets servers quickly skip expensive full lookups for obvious non-matches.

💰

Blockchain

Bitcoin uses Bloom Filters so lightweight clients can check if a transaction is relevant without downloading the full blockchain.

🔡

Spell Checkers

A Bloom Filter of valid words lets spell checkers quickly flag obviously wrong words without a full dictionary lookup.

📡

CDN / Caches

Track which URLs have been requested before. Only cache "popular" content — saving memory by avoiding one-hit-wonders.
